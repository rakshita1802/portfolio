# Rakshita N - Developer Portfolio

A modern, Neo-Brutalist developer portfolio built with React and Vite. It features a unique, aggressive design aesthetic with an interactive terminal, dynamic particle backgrounds, and a focus on high-performance web development.

## Features

- **Neo-Brutalist Design**: Aggressive borders, raw colors, and sharp corners for a unique aesthetic.
- **Interactive Terminal**: A fully functional CLI terminal simulation hidden in the UI.
- **Cinematic Transitions**: Smooth page load preloaders and section transitions.
- **Fully Responsive**: Carefully crafted to look perfect on mobile, tablet, and desktop.
- **Netlify Ready**: Pre-configured for instant CI/CD deployment on Netlify.

## Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (CSS Variables for theming)
- **Icons**: Lucide React
- **Animations**: Canvas Confetti

## Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/rakshita1802/portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Customization
All the portfolio data (projects, skills, education, etc.) is centralized in `src/data/portfolioData.js`. Edit this single file to update your portfolio's content!
